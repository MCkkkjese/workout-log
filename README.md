# 重訓紀錄網頁（Workout Log）

個人重訓紀錄與統計儀表板，採純靜態前端（HTML / CSS / JS）部署於 **GitHub Pages**，後端透過 **Google Apps Script JSON API** 讀寫個人 Google 試算表「重訓紀錄」，並與手機 AppSheet 共用同一份資料庫。

👉 **線上網頁**：https://mckkkjese.github.io/workout-log/

---

## 系統架構
- **前端網頁（GitHub Pages）**：[index.html](./index.html)（單頁式應用，含 `localStorage` 資料快取與 Cookie 設定儲存）
- **後端 API（Google Apps Script）**：[apps-script/Code.gs](./apps-script/Code.gs)（提供 `doGet` / `doPost` JSON API，支援選填 `API_TOKEN` 密碼保護）
- **資料庫（Google Sheets）**：`重訓紀錄` 試算表（含 `推日紀錄`、`拉日紀錄`、`腿日紀錄`、`訓練紀錄`、`動作`、`設定`、`身體狀況`）

## 目前功能一覽

### 1. 底部 Liquid Glass 懸浮導覽列（首頁｜重量｜＋｜達標｜其他）
- **首頁**：
  - 頁首顯示日期與「重訓紀錄」大標（支援**往下拉重新整理**）。
  - **主卡**：上半部為 210px 置中本週訓練進度圓環、剩餘天數提示與推／拉／腿完成標籤；中間以細線分隔；下半部為本月出勤率百分比、14px 橫向進度條＋iOS Emoji 等級（`😄` ≥ 70%、`😐` 40%–69%、`😭` < 40%）與「已練 X 次 ／ 應練 Y 次」。
  - **第二張卡**：兩欄合併顯示「上次訓練」與「連續達標（含歷史最高連續週數）」。
  - **第三張卡**：身體狀況最新狀態文字與「更新 ›」快速入口。
- **重量**（原「動作重量」）：
  - 推日／拉日／腿日切換，大字顯示上次的熱身、⭐正式、⭐突破重量，並於卡片下方顯示歷史最強重量與最近升降（`▲` / `▼`）。
- **＋**（底部導覽列中央凸起咖啡色圓鈕）：
  - 點擊開啟記錄訓練／身體狀況選單（支援「今天沒做」略過，並內嵌練完身體狀況選填）。
- **達標**（合併「本週進度」＋「出勤」）：
  - 顯示本週每天標記、各訓練日距上次天數與下次訓練建議，以及本月動態出勤率、出勤日曆、近 6 個月結算、近 8 週長條圖與累計次數。
- **其他**（原「修改紀錄」，四大子分頁）：
  - **訓練紀錄**：依月份列出，點擊可修改日期、重量、次數，或刪除（需按兩次確認）。
  - **身體狀況**：顯示最新身體狀況、近 30 天常見狀況、近 14 筆疲勞趨勢折線圖與快速新增按鈕，下方可依月份點選任意紀錄進行修改或刪除。
  - **動作管理**：可 **新增動作**（寫入 `動作` 分頁並在對應訓練日紀錄表新增 4 欄），或 **修改現有動作名稱／部位／預設重量**（同步更新菜單與紀錄表欄位標題）。
  - **雜項**（外觀與設定）：提供奶茶色／深色模式切換、手動同步按鈕與折疊收納的「進階：資料庫連線設定」。

### 2. 視覺、更新與防快取機制
- **米奶茶色系＋雙字體排版**：
  - 背景米色 `#F2EDE6`、卡片 `#F9F6F1`、邊框 `#E4DBD0`、主文字 `#3A2F28`、次要文字 `#6E6259`、主色咖啡 `#9A6B4F`、完成綠 `#4F7A57`。
  - 標題採用 **思源宋體（Noto Serif TC）**，內文採用 **思源黑體（Noto Sans TC）**，所有介面圖示皆為線條 SVG，支援深色模式切換與 Cookie 儲存設定。
- **PWA 主畫面圖示**：
  - 透過 [manifest.json](./manifest.json) 與 `apple-touch-icon.png`（iOS `🏋🏻` Emoji 搭配柔和白漸層背景），Safari 加入主畫面／Dock 後可像獨立 App 一樣開啟。
- **無感自動清快取更新**：
  - 開啟時先秒讀快取不卡頓，同時背景以 `cache: 'no-store'` 檢查 [version.json](./version.json)；若偵測到 GitHub 上有新版本，自動重新載入最新頁面，避免手機瀏覽器殘留舊版快取。
  - 頁面最下方顯示目前網頁 **版本號與更新時間**。

## 本地預覽與後端部署

### 本地預覽
```bash
python3 -m http.server 8080
```
用瀏覽器開啟 `http://localhost:8080` 即可測試。

### 更新 Google Apps Script 後端（若有修改 `apps-script/Code.gs`）
1. 開啟 Google Apps Script 專案「重訓儀表板」，將 [apps-script/Code.gs](./apps-script/Code.gs) 貼入 `程式碼.gs` 並存檔。
2. 點右上角 **「部署」→「管理部署作業」→ 編輯**：
   - 版本：**建立新版本**
   - 執行身分：**我**
   - 誰可以存取：**任何人**（建議於 `Code.gs` 設定 `API_TOKEN` 並於網頁 `⚙️` 進階設定填入相同密碼）
3. 按 **部署** 即可生效。
